# Student Planner

A simple, beginner-friendly Student Planner built with **HTML, CSS and JavaScript**. It helps students organise assignments and keep track of study tasks.

## Features
- Add a task with its subject, due date and priority
- Mark tasks as completed
- Delete tasks
- Filter all, pending and completed tasks
- View total, completed and pending task counts
- Automatically save tasks in the browser using Local Storage
- Responsive layout for desktop and mobile screens

## How to run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation is required.

## Project files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — task features and Local Storage

## Technologies used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
